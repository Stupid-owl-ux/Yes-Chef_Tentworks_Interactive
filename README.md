# Yes-Chef_Tentworks_Interactive
This repo holds the files for the unity game called Yes, chef as a project given by the company Tentworks Interactive.


# Yes Chef! - Tentworks Interactive Dev Test

## Controls
WASD - Move,
E - Interact,
ESC - Pause

## Gameplay
Fulfill customer orders by collecting and preparing ingredients.
Vegetables must be chopped, meat must be cooked, and cheese can
be served directly.

Each game lasts 3 minutes.

## Technical
Engine: Unity 6.4.0
Language: C#
Platform: Windows
